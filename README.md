# Google Cloud for Xo (design stage)

A port of Google's Go SDK for Google Cloud, starting with
google.golang.org/api's REST packages, generated from the Discovery
documents Go itself ships and checked against Go byte for byte.

Status: design. The records in [docs/decisions](docs/decisions/README.md)
were accepted by the owner on 2026-11-07; generation starts next. Local
only until the owner approves publishing.

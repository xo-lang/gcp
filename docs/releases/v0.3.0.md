# v0.3.0

The Google Cloud SDK for Xo, with credential discovery moved into
modules of its own: the root module (`github.com/xo-lang/gcp`), the
hand-written `storage` and `bigquery` clients, `auth/credentials`,
`compute/metadata`, and all 667 API modules, 672 in all, tagged v0.3.0
at one commit. Requires Xo 0.51.0 or later.

A community SDK for the Xo language. Not affiliated with or endorsed by
Google. Google Cloud is a trademark of Google LLC.

## Upgrading from v0.2.0

- **Credential discovery is its own module**
  ([decision 0014](../decisions/0014-credential-modules.md), breaking).
  `auth/credentials` (Application Default Credentials, credential files,
  `detect_default`) and `compute/metadata` are modules, so the root
  module reaches only what a request needs, `clock`, `net.dial` and
  `rand`, as in v0.1.0. v0.2.0's root added `env` and `fs.read`, which
  every program accepted in its xo.lock whether or not it detected
  credentials.
- **Import paths do not change.** A program that uses
  `auth/credentials` adds its require:

      xo get github.com/xo-lang/gcp/auth/credentials@v0.3.0

  and accepts that module's effects there, where `xo audit` shows them
  by name. A program that hands a client its own token
  (`auth.TokenProvider`, `option.ClientOptions`) needs nothing new.
- `auth.compute` (the metadata server's tokens) stays in the root and
  takes a `metadata.Client`.

## Install

    xo get github.com/xo-lang/gcp@v0.3.0
    xo get github.com/xo-lang/gcp/calendar/apiv3@v0.3.0

Get the API versions your program uses; each requires the root at
v0.3.0.

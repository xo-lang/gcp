# v0.3.1

Finishes v0.3.0's module split (decision 0014): every module, 672,
tagged v0.3.1 at one commit. Requires Xo 0.51.0 or later.

A community SDK for the Xo language. Not affiliated with or endorsed by
Google. Google Cloud is a trademark of Google LLC.

## What changed

v0.3.0's root module still required `compute/metadata`, for
`auth.compute`, so every program's xo.lock listed that module with
`env` and `fs.read`, though only credential discovery uses it. Now
`auth.ComputeProvider` takes an `auth.MetadataSource` (an interface with
`fetch(suffix)`), which `metadata.Client` has, and the root requires no
module. A program that passes its own token has only modules at
`clock`, `net.dial` and `rand` in its lock.

## Upgrading from v0.3.0

Bump the versions; nothing else changes:

    xo get github.com/xo-lang/gcp@v0.3.1

`auth.compute(metadata_client, clock)` takes the same arguments. Code
that read `ComputeProvider.client` as a `metadata.Client` (its
`project_id`, say) keeps its own `metadata.Client` instead.

# v0.1.0

The first release of the Google Cloud SDK for Xo: the root module
(`github.com/xo-lang/gcp`) and every API module under it, 668 in all,
tagged v0.1.0 at one commit. Released with Xo 0.46.0; requires Xo 0.45.0
or later.

A community SDK for the Xo language. Not affiliated with or endorsed by
Google. Google Cloud is a trademark of Google LLC.

## What is in it

Coverage is from [docs/reports/gcp-go-coverage.md](../reports/gcp-go-coverage.md).

- **667 API modules**: every API version google.golang.org/api v0.311.0
  ships, each generated from the Discovery document Go's package was
  built from, at Go's package path (`storage/v1`, `compute/v1`, ...).
  discoveryengine/v1 and v1alpha come from the older document Go built
  them from (v0.293.0; [not-generated.md](../reports/not-generated.md)).
- **The core** (the root module): `gensupport` (requests, retries,
  pagers, media upload and download), `googleapi` (errors and URL
  helpers), `option` (endpoint, API key, quota project, timeout,
  credentials) and `auth` (a token provider interface and a static
  token).

## How it is checked

Every method of every module is called in Go and in Xo with the same
arguments against the same fake service, and the requests, the responses
served and the decoded results are compared: 34,228 vector tests, run
natively on darwin/arm64 and linux/arm64. No test calls Google Cloud.

## Not in it

- Credential discovery (Application Default Credentials, service account
  keys, metadata server): a program supplies an `auth.TokenProvider`.
- `cloud.google.com/go`'s gRPC clients (Pub/Sub, Spanner, Bigtable,
  Firestore and the GAPIC clients), which wait for gRPC in std
  ([decision 0007](../decisions/0007-grpc-deferred.md)).

## Install

    xo get github.com/xo-lang/gcp@v0.1.0
    xo get github.com/xo-lang/gcp/storage/v1@v0.1.0

Get the API versions your program uses; each requires the root at v0.1.0.
